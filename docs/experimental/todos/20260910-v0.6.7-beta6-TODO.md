- [x] 拆分 Reflex 的接口可用、请求结果与实际启用状态。分别记录 `SetSleepMode`、`GetSleepStatus` 返回值及 `bLowLatencyMode`；不再将“查询成功但状态为 Off”伪装为驱动返回的 `NVAPI_NOT_SUPPORTED`。区分真正调用失败、驱动未启用、呈现暂时不可用和停止；遵守控制面板覆盖，不强制绕过。
- [x] 修正 DLSSFG 呈现等待统计：当前 `pacingEnd = pacingStart` 导致 `pacingWait` 恒为零。累计同一 FIFO 任务从首次等待到完成／丢弃之间的调度等待，分别记录容量重试和 CPU 工作；GPU 执行耗时另由实机工具验证，避免重试重复计数。

- [x] 基础 FPS 由单一调度入口负责。优先以 Async 为基线；Reflex 实际可用时默认低延迟 On、Boost Off，DLSSFG 的额外驱动限帧间隔暂保持 0。纯 Reflex 驱动限帧需独立验证 x2/x3/x4 单位和行为后再决定是否开放。
