## 4. 两项非阻塞细节

1. **查询失败的可观测性（已处理）**：`GetDesc1` 失败记录 HRESULT 并注明 LUID 不可用；打开、查询和关闭适配器失败记录操作名、完整 LUID 和十六进制原始 NTSTATUS，不将 NTSTATUS 当作 HRESULT。日志只产生于枚举／设备选择的失败分支，成功查询不写日志，不缓存类型结果以免热插拔后过期。打开或查询失败继续保留候选项，已打开的句柄在查询失败后仍关闭。
2. **极旧索引配置**：只有索引、没有 vendor/device ID 的旧配置若指向被排除条目，会回退到“自动”，无法保证选择原来的 NVIDIA 实体卡。验收需明确这一兼容边界；不以同名描述猜测设备或误写另一实体卡。保留当前回退规则并提供明确说明，本轮不扩大迁移范围。
