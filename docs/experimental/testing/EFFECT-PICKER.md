# 0.6.7-local 效果器选择器（r1 fix1）

在「效果组」中点击「添加效果器」，左侧按用途和子分组筛选，右侧搜索和选择单个效果器，底部通栏显示详情。选择器可超出主窗口，最大 820×800 DIP，按按钮所在显示器的工作区和 DPI 留出边距。采用 Magpie 现有 WinUI 主题的圆角 Flyout、背景材质、半透明分区和分隔线。

- 搜索覆盖全部分类，匹配名称、用途、关键词和旧名称；点击分类会清空搜索。列表保留名称与一行用途说明。
- 点击主分组名称筛选整组并展开；点击固定的加减号只展开／收起。多个分组可以同时展开；在同一页面再次打开选择器时保留展开和分类状态。子分组被收起时，父组的选中标记与右侧分类路径仍提示当前筛选。
- 同族变体默认折叠：CuNNy（含原版／CuNNy2 两代）、NNEDI3、Anime4K、RAVU、SMAA、FXAA、xBRZ、FSRCNNX、CAS、FSR 1、NIS、XeSS 补帧。标题仅展开／收起，具体效果器才添加；筛选后只有一个成员时直接显示该成员。CRT、Sharpen 等不同算法集合不按文件夹合并。
- 家族仅显示当前筛选的成员，名称和数量随结果变化；变体采用自然数字排序。搜索临时展开匹配家族，可手动收起；清空后恢复普通浏览状态。
- 右侧 `A–Z／#` 在当前结果中跳转并聚焦，保留搜索与分类。常用高度下提供两列 24 DIP 的字母按钮，高度不足时显示 `A–Z #` 按钮，展开 6 列字母网格。没有结果的字母禁用；数字、符号和非拉丁字母归入末尾的 `#`。
- 分类支持上下键导航、左右键展开／收起；效果器支持上下键导航和 Enter 添加。悬停或聚焦更新底部详情，移开后保留内容。
- 单击效果器立即追加到当前组末尾，继续使用原有拖动排序。添加前检查补帧冲突等组合限制；说明里提供下一步。
- 添加面板只选择效果器。RTX Video 强度通过效果组的参数按钮和工具栏参数面板调整。

## DLSS SR 与面板密度

DLSS SR 与 FSR2／3／4、XeSS SR 一同归入「放大与超分 → 时序重建」，显示名为 `DLSS SR`，保存 ID 仍为 `DLSS\DLSS_SR`。用途和组合建议围绕主要缩放步骤展开；保留原始相机抖动／真实深度缺失、可选估算运动、当前 Preset J 以及用户反馈的 L／M 轻微抗锯齿收益说明。

弹窗首选高度从 640 增至 800 DIP（+25%），底部说明区从 192 减至 144 DIP（−25%）；上下区域采用 82:18 比例，在小屏幕上一起收缩。字号统一减少 1 DIP：名称和搜索 13、分类和正文 12、摘要 11、计数与索引 10、说明标题 15。保留原有按钮内边距，字母索引的固定点击尺寸不变。

## RTX Video

正式 ID 为 `RTXVideo\RTXVideo_Denoise`、`RTXVideo\RTXVideo_VSR`；`strength` 参数值 0／1／2／3 对应低／中／高／极高，新添加默认 1（中档）。Denoise 保持输入尺寸，VSR 使用配置的输出尺寸。

八个旧档位 ID 在配置读取和效果组导入的共同路径中精确迁移，保留原档位、位置、尺寸与其他参数。再次加载不重复迁移；之后保存／导出使用新形式。原配置在迁移写入前由现有配置备份机制保存。旧名字仍可搜索，源码与发布包改为 155 个 HLSL、155 个正式选择入口；原 161 项 review 保留为历史资料。

运行中切档在后台渲染线程、两帧之间创建并加载候选模型，沿用已同步的输入／输出资源。加载成功后替换句柄；失败保留原模型，回退相应参数并提示尝试较低档位或提供日志。回退会核对当前值，避免覆盖之后的修改。工具栏分别显示保存状态、正在应用和失败回退；实时应用中的值不会被计作需要重启的变化。

`NvVFX_Load` 可能产生短暂停顿，候选模型也会临时增加显存占用。本实现没有承诺无中断热切换；具体驱动下的四档画质、时延和资源占用由用户验收。

## DLSSNR 自动 HDR

参数按钮和工具栏已移除 `HDR Processing Path`、`Experimental HDR Scale` 及对应空分组；旧配置中的这两个值在读取／导入时移除，保留风格、细节与运动参数。

HDR 关闭时沿用 SDR 路径。HDR 开启时，在效果资源创建前核对输入是否经过捕获层的 canonical 转换、颜色信息是否有效、后端 FP16 能力是否可用；满足条件后使用 FP16 边界，倍率固定为中性的 1。输入和输出转换分别除以、乘以当前 SDR 白点与 80 nit 的比值。原始纹理是 FP16 本身不会触发该路径。

捕获层对缺失颜色信息已有明确的 SDR 默认描述，记录 inferred 信息后再归一化；白点和颜色边界随输入更新，格式在一个运行会话中保持稳定，尺寸变动由现有 Resize 流程重建资源。未新增逐帧亮度分析或自动猜测实验倍率。

FP16 路径的高光、颜色和实际 AI 观感仍需验证；该路径下现有输入分辨率调整／残差重建不可用，工具栏将相关参数标为不可用。其他风格参数保留。未验证 NVIDIA 的私有模型归一化曲线；边界转换的数值往返通过不等于模型无损。

## 2026-09-08 回归修复

用户报告参数设置失效、RTX 强度显示为空白，以及打开选择器闪退。日志错误为 `0x80070057`，同次转储为 `Windows.UI.Xaml.dll` 的未处理异常 `0xc000027b`。转储未包含原始 stowed exception 堆内存；具体触发点通过独立 XAML 控件测试复现。

根因：新增强度控件把 `single_threaded_vector<hstring>` 交给 XAML `ItemsSource`，该集合没有 XAML 需要的 `IInspectable` 集合接口。设置时抛出参数异常。在效果器行模板中，这一步排在 `HasParameters` 和 `Parameters` 绑定之前，会中断后续初始化；在选择器构建中，同一错误传播出点击事件并导致退出。

修复：统一使用可供 XAML 绑定的集合，RTX 强度纳入现有参数组；打开选择器的局部异常会记录错误并提示重试，保留效果组。`tests/EffectChoiceItemsTests.cpp` 的 `--xaml` 测试在无可见窗口的独立进程中验证真实 `ComboBox`：旧集合抛 `E_INVALIDARG`，新集合正常选择四档并读取选中值。未操作用户界面，也未启动缩放或 GPU 效果器测试。
