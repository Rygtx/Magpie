# 0.6.7-local 效果器选择器

功能：带用途说明和组合建议的效果器选择器。

在「效果组」中点击「添加效果器」：上方搜索名称、中文用途、算法家族或旧名称；左侧按用途和子分类筛选，右侧显示单个效果器。搜索覆盖全部分类，点击分类会清空搜索。

- 悬停或键盘聚焦可查看用途、场景、变体差异、推荐理由、组合位置、输出尺寸和使用条件。HDR 仅显示需要注意的情况。
- 单击效果器立即追加到当前组末尾，Enter 执行同一操作；上下方向键在可见效果器间移动。添加后沿用原有拖动排序。
- 组合建议不自动调整顺序；补帧和帧率控制按实际运行时调度解释。已有补帧时，其他补帧项仍可查看，添加前说明要先移除哪一项。
- 161 个内置 HLSL 对应 155 个选择入口。RTX Video 合并成 Denoise、VSR 两项，强度低／中／高／极高可选；新添加从低档开始，已有配置精确保留原档位。操作强度控件只改变档位，点击条目才添加。
- 已有效果组中的 RTX Video 点击「参数设置」后调整强度，列表行不直接显示参数控件。变更在下次启动缩放时生效；保留当前项的尺寸规则、参数与位置。
- XeSSFG 显示名称去掉 ZeroMV，原有运动估算选项保持不变。保存和导出继续使用旧内部 ID；本次无内部 ID 迁移。
- 自定义或未收录的效果器仍可添加，归入「自定义／未归类」，说明提示参考作者文档。

说明目录来自本轮 161 项 review，目前为中文内容；分类和推荐仍可继续复核。画质、HDR 和具体性能不因接入选择器而视为完成实测。浏览、搜索和添加不创建缩放窗口或初始化效果器 GPU 后端。

## 2026-09-08 回归修复

用户报告参数设置失效、RTX 强度显示为空白，以及打开选择器闪退。日志错误为 `0x80070057`，同次转储为 `Windows.UI.Xaml.dll` 的未处理异常 `0xc000027b`。转储未包含原始 stowed exception 堆内存；具体触发点通过独立 XAML 控件测试复现。

根因：新增强度控件把 `single_threaded_vector<hstring>` 交给 XAML `ItemsSource`，该集合没有 XAML 需要的 `IInspectable` 集合接口。设置时抛出参数异常。在效果器行模板中，这一步排在 `HasParameters` 和 `Parameters` 绑定之前，会中断后续初始化；在选择器构建中，同一错误传播出点击事件并导致退出。

修复：统一使用可供 XAML 绑定的集合，RTX 强度纳入现有参数组；打开选择器的局部异常会记录错误并提示重试，保留效果组。`tests/EffectChoiceItemsTests.cpp` 的 `--xaml` 测试在无可见窗口的独立进程中验证真实 `ComboBox`：旧集合抛 `E_INVALIDARG`，新集合正常选择四档并读取选中值。未操作用户界面，也未启动缩放或 GPU 效果器测试。
